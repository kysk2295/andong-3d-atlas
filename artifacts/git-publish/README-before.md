기존 지도 첫 화면을 유지합니다. `?experience=relay`에서 체험합니다. GTA와 같은 상용 게임 규모의 도시·교통 AI·물리 엔진을 구현했다는 의미는 아닙니다. 짧은 거점 연결과 직접 조작으로 구성된 웹 체험이며 실제 가맹점 인증·결제 연동은 없습니다.

첫 화면은 지도가 화면 전체를 채우고 제목·탐색 패널·날씨와 계절·지도 도구·장소 정보만 위에 떠 있는 구성입니다. B 코스와 C 사진은 기존의 작업별 구성을 유지합니다. 좁은 화면에서는 접는 탐색과 풍경 메뉴를 사용합니다.

하회마을·병산서원·도산서원·봉정사의 기존 OSM 원본에서 담장 선, 숲 경계, 이름 있는 건물·나무 좌표를 추가 추출했습니다. 담장 선은 각각93·7·40·5개입니다. 출입구의 끊어진 선을 임의로 닫지 않고 지형 위에 배치합니다. 하회마을은 골목·삼신당·만송정 숲, 다른 명소는 경내 가까이 보기를 제공합니다.

전통 건물에는 따뜻한 벽체·목재 창살·기와 질감, 하회마을에는 둥근 초가 지붕도 표현했습니다. 방문객은 골목에서 소규모 무리로 걷고 잠시 멈추며 모자·가방을 구분합니다. 만송정은 수록된 숲 경계 안에 소나무 풍경을 연출했습니다. 건물 윤곽·담장·숲 경계의 출처와 달리 **개별 지붕 재료의 배정·외관·나무 배치·사람 수와 행동은 미니어처 연출**이며 현장 전수조사 결과가 아닙니다.

기존 원본으로 추가 자료만 재생성하려면 `python3 scripts/prepare-heritage.py`를 실행합니다. 전체 지역 재생성에도 이 단계가 포함됩니다. 여행 중 도로와 건물 자료가 겹치는 구간은 전체 지도 시점으로 보여주며, 다음 정상 구간에서 사용자가 선택한1인칭·따라가기 시점으로 돌아옵니다.

## 지도 기호 정리

식당·체험·혜택의 큰 입체 구체와 연결 기둥을 작은 GIS 방식 기호로 바꿨습니다. 원형·마름모·사각형으로 유형을 구분하며, 기본 기호는7–8px(마름모 회전 후 외접 폭 약11px), 선택 테두리는14px입니다. 확대해도 기호 크기가 커지지 않고 실제 좌표에 고정됩니다. 누를 수 있는 영역은24px입니다.

겹치는 지점은 선택 장소·추가 혜택·기존 혜택 순서로 정리하고, 확대하면 주변 지점이 다시 나타납니다. 지형 좌표를 밀어내거나 자료를 삭제하지 않으며 가려진 지점은 기존 장소 목록에서도 선택할 수 있습니다. 이름은 마우스/키보드 초점에서 표시하고 클릭하면 장소 정보를 엽니다. 지도 경로는 도보 점선·차량 실선으로 구분합니다. 1인칭 여행에서는 지도 기호를 숨깁니다. 실제 GIS 분석 엔진이나 실시간 교통 자료로 변경한 것은 아닙니다.

## 외곽 상세 시각화 (v1.5)

원도심–월영교 한 구역에만 있던 상세 표현을 외곽93개 자료 묶음으로 확장했습니다.5개 주요 거점과88개 일반 읍면 구역이며, 확대하거나 장소를 고르면 필요한 구역을 불러옵니다. 상세 구역 밖의 전역 지형은 배경으로 유지합니다. 아래 수는 각 묶음의 건물 윤곽 레코드이며 겹치는 구역을 합쳐 실제 고유 건물 수로 해석하면 안 됩니다.

| 상세 거점 | 건물 윤곽 | 도로·보행 구간 | 추가 표현 |
|---|---:|---:|---|
| 안동역·터미널 | 2,058 | 826 | 실제 위치 선로24구간, 움직이는 열차 모형, 주차선, 차량·보행자 |
| 하회마을·부용대 | 629 | 168 | 전통 지붕·목재 기둥 표현, 마을 길과 강변, 농경지 |
| 병산서원 | 68 | 51 | 서원 권역을 함께 보는 시야, 전통 건축과 강변 길 |
| 도산서원 | 92 | 61 | 상세 표고와 건물 하단 보정, 나무·보행로 |
| 봉정사 | 118 | 77 | 경사지 건물 접지, 지붕·기둥과 사찰 주변 길 |

지형은 AWS Terrain Tiles z13 자료를 약18m 간격 표시 격자로 만들었습니다. 측량 정확도를 뜻하지 않습니다.5개 거점은 OSM API 원본을 추가 수집했고, 일반88개 구역은 기존 공개 지도와 GBA 건물 자료를 재사용합니다. 미수록 건물이나 POI를 임의로 생성하지 않습니다. 전통 지붕·목재 표현·창문·주차선·농경지 무늬·수목·차량/열차/사람은 미니어처 해석이며 실제 외관·수목 위치·운행 빈도 조사 결과가 아닙니다.

도심과 외곽 최대2개 장면을 GPU에 유지하고 오래된 외곽 장면은 해제합니다. 모바일은 사람·차량·수목 수를 줄입니다. 외곽 자료 전체는 JSON 약54.3MB/gzip 약10.7MB지만, 처음부터 모두 내려받지 않습니다. 불러오기 실패는 재시도 안내를 제공합니다.

재생성에는 기존 전역/도심/GBA 자료와 Python의 `shapely`, `pillow`가 필요합니다. 원 응답은 `.cache/regions` 등에 저장합니다.

```sh
python3 scripts/prepare-regions.py
python3 scripts/prepare-journey.py
npm run build
```

KTX 여행의 출발점은 공개 지도에 등록된 안동역 출입구(OSM node13065380449)입니다. 추가 보행로와 실제 도보 경로를 기준으로 역 정류장을 선택해 약106m로 연결했습니다. 화면의 관광지 입구 표식과 여행 경로 좌표는 유지하며, 서원·하회마을의 첫 카메라 구도만 전체 권역을 보기 좋게 조정했습니다. 실제 운행 노선이나 시간표 검증을 대신하지 않습니다.

## 접지·여행 높이 보정

역사 건물의 인접한 지면 보정이 서로 섞여 기초벽이 길어지던 문제를, 같은 지형 삼각형의 접점들을 함께 조정하는 방식으로 보완했습니다. 원 표고·건물 좌표를 수정하지 않으며 기존 표시용 지면에서 추가 이동은 최대4m로 제한하고 구역 바깥 경계점은 유지합니다. 이는 측량 정밀도 향상이 아닌 미니어처의 표시 보정입니다.

월영교를 걷고 장소에 도착할 때 다리 상판 높이를 지면 높이로 덮어쓰던 오류도 수정했습니다. 여행자가 도착 후 다리 아래로 내려가지 않고 접근한 구간의 상판 위에 남습니다. 이 수정은2026-09-29 v1.5.1에 공개 반영했으며 v1.6에도 포함합니다.

## 코스 여행·장소·혜택 (v1.3)

`여행 (Trip)` 탭 또는 `http://localhost:4174/?journey=1`에서 시작합니다.

1. 원도심, 안동역 KTX 하차, 안동터미널, 하회마을 입구 중 출발 거점을 고르고 식당·체험·출발 시각을 선택합니다. 안동역·터미널 코스는 정류장까지 도보, 대기, 승차, 하차 후 도보를 포함합니다.
2. 식당·체험·혜택 표식 또는 목록을 누르면 주소, 수집한 운영 시간, 가격 확인 상태, 혜택, 출처를 확인할 수 있습니다. 좌표를 연결한 장소 51곳 중 식당·카페38곳, 체험2곳(제안1곳), 기존 주민증 혜택6곳을 포함합니다. 기존 가맹 목록 중 좌표 미확인21곳은 이름만 제공합니다.
3. `이 코스 여행하기`로 자동 보행, 버스 승객 시점, 여행자 따라가기, 전체 지도 보기를 전환합니다. 1·2·4배 압축 재생, 이전/다음 구간, 둘러보기, 장소에서 일시정지, 종료 후 지도 복원을 지원합니다. 영수증 인증과 혜택 사용은 시연이며 실제 인증·결제·예약이 아닙니다.
4. 귀가 열차 출발 시각과 역 도착 여유를 입력하면 월영교 권장 출발 시각을 계산합니다. 112번은 수집한 귀환 출발 시각을 사용하고 환승·역 이동 시간은 입력 가정입니다. 놓친 버스를 뒤늦게 탑승하는 장면을 만들지 않습니다. 제안 저녁 이동은18:30–21:00 범위를 지킵니다.
5. 현재·기본·확대안을 같은 출발 조건에서 비교합니다. 원본의 연간 추가 소비·체험 결제·주민증 조건형 기대효과와 여행 종료/귀가 가능 여부를 함께 표시합니다. 사업 전체 추정과 개인 여행 지출은 별개입니다.
6. 혜택 장소, 할인율, 적용 시간을 추가·삭제하고 코스에도 넣을 수 있습니다. 원도심2곳/월영교2곳 예시 배치를 비교하며 공개 도로망의 도보10분 접근성 전후를 계산합니다. 추가 위치만으로 검증되지 않은 매출 증가를 계산하지 않습니다.

여행 데이터는 `scripts/prepare-journey.py` → `public/data/journey.json`(2.36MB, gzip0.53MB)으로 저장합니다. 도로망36,661개 정점·39,367개 구간, 공개 BIS 정류장282개, 서로 다른 지도 자료 경계의35m 이내 연결377개를 사용합니다. 하회마을 연결은 캐시한 OSRM/OSM 도로 경로를 사용합니다. 실제 BIS 운행 경로·통행 가능성·정류장 접근성을 검증한 길찾기 서비스가 아닙니다. 실시간 운행·열차 조회·예약 기능은 없습니다.

1인칭에서는 미니어처의4배 높이 강조를1배로 낮춥니다. 도로 가장자리·보행로와 교량 높이를 따르며 건물 겹침을 피할 연속 경로가 없으면 해당 구간을 전체 지도로 표시합니다. 월영교 모형은 양 끝뿐 아니라 중간 꺾임 좌표도 따르며, 교각과 열린 정자가 중앙 보행 통로를 막지 않도록 했습니다. 외관·정자·정류장·간판은 설명용 모형이며 현장 실측 복원이 아닙니다. 배경 인물·차량은 눈높이 비율을 조절하고 카메라 바로 앞의 개체는 가립니다. 충돌 물리·군중 행동 모형은 없습니다.

메뉴·체험 가격 미확인으로 예상 지출과 할인 금액은 계산하지 않습니다. 혜택 설정과 인증 시연 상태는 현재 페이지 안에서 유지하며 새로고침 시 초기화됩니다.

지형과 건물 높이는 지도에서4배, 1인칭 여행에서1배로 표시합니다. 내륙 표고 자료에서 발견된 음수 이상치 3점은 주변 5×5 격자의 유효 표고 중앙값으로 보정하고 `terrain.json`의 `correctedSamples`에 원본·대체값을 보존했습니다. 전역 수계는 표고 격자에 윤곽을 입혔고, 상세 수계는 7개로 병합한 다각형의 수면을 평탄하게 표현했습니다. 수계 안 DEM의 하위 25% 높이를 바탕으로 렌더링 지형만 평탄화하며 `district.terrain` 원본 표고는 그대로 유지합니다. 수리학적 수면 모형은 아닙니다.

기존 타일의 6,486 Polygon에 GlobalBuildingAtlas 연구 데이터의 비중복 건물 윤곽 54,640개를 보충했습니다. 이는 안동 행정경계 안의 고유 건물 수나 전수 조사 결과가 아닙니다. 지형 표시 bbox는 인접 지역 일부를 포함하며, 연구 데이터의 분할·인식 오류와 지도 누락이 남아 있습니다. 원천의 위성 추정 높이를 사용하고, 기존 건물의 높이가 없으면 6m를 적용합니다. 지붕 테두리·옥상 설비·창문·나무·가로시설 형태는 미니어처 표현이며 건축 외관이나 수목 현장 조사 결과가 아닙니다.

GBA의 동아시아 타일을 스트리밍해 표시 범위 55,223개를 추출했고 모두 높이 정보와 연결했습니다. 기존 건물과 면적/중심점 기준으로 겹치는 583개를 제외해 54,640개를 보충했습니다. 상세 범위에 해당하는 1,253개도 `district.json`에 연결했습니다. OSM과 GBA의 경계 차이 때문에 완전한 중복 제거를 보장하지 않습니다.

- 차량 차체·창·바퀴·전조등, 사람 팔다리 보행, 원본 위치의 횡단보도·정류장과 일반 가로시설을 표시합니다. 시설의 실제 형태·모든 보도의 존재를 보장하지 않습니다.
- 수면·소형 선박·탑승객·월영교 난간과 정자를 표현합니다. 교량 구간의 도로·보행자는 수면이 아니라 별도 교량 높이를 따릅니다. 교량 높이는 양안 표고에서 정한 표현값이며 구조 실측값이 아닙니다. 카메라가 언덕 속으로 들어가지 않도록 시야선을 검사합니다.
- 기본안/확대안의 모형과 원본 기대효과·주민증 조건형 추정값을 연결합니다. 부지·부스 수·버스 수는 확정 운영계획이 아닙니다.
- 전역 건물은 한 번에 메시로 조립해 수만 개 임시 지오메트리를 만들던 비용을 줄였습니다. 데이터는 실행 시 외부 API 호출 없이 로컬 정적 파일에서 읽습니다.

### v1.15.0 — 문서 사진 기반 공간 재구성과 방향키 수정

↑↓는 전후 이동, ←→는 회전으로 변경했다. 캔버스에 포커스가 없어도 조작되며, 모달·입력칸·체험 중에는 해당 조작을 방해하지 않는다. 한글 입력 상태에서도 물리 WASD 키를 인식한다. 모바일 이동 버튼의 짧은 탭, 포커스/화면 전환 시 멈춤도 보완했다.

Google 기획 문서의 4개 하위 탭에서 이미지 114개를 추출하고 단계별 목록·확대 보기를 추가했다. 식당의 벽돌 벽·금속 다리·검은 의자·조명을 재구성하고, 실사진 기반 목재·벽돌·직물 재질과 나무 그릇 모델을 적용했다. 찜닭의 곡면·양념·당면, 도자기 다관·인물 비례·손 모양을 세분화하고 접촉 그림자를 추가했다. 반투명 김은 그림자 계산에서 제외해 덩어리처럼 보이는 현상을 막았다. 작은 화면과 가벼운 화면 설정에서는 추가 그림자를 끈다.

꽃을 다관에 넣는 판정 높이를 실제 다관 높이에 맞추고, 차의 흐름을 모델의 주둥이 좌표와 연결했다. 기존 지도 첫 화면과 저장된 릴레이 진행 기록은 유지한다. 모든 공간은 사진 참고 재구성으로 완전한 실사/실측 복제는 아니다.

# v1.29 승객 눈높이의 버스 이동

- 지도 코스와 릴레이에 공유하는 미터 단위 버스 내부: 운전석, 기사 1명·승객 6명, 좌석, 창문, 손잡이, 하차 벨과 안내등.
- 지도 여행은 차량을 숨기던 테두리 연출 대신 실제 차량 안에 카메라를 둔다. 높이 4배 지도와 1배 여행 전환을 보정하며 창가·통로 선택을 제공한다. 차량 구간은 거리 기준 약 32km/h로 재생하고 배속·다음 구간을 유지한다.
- 릴레이는 가까운 상가·보도·보행자 14명·맞은편 차량과 강변을 지나는 34초 주행. 주행 중 드래그/방향키로 둘러보기, 하차 벨, 경로 전환, 다시 타기, 통로를 따른 하차 이동.
- 승객의 고개, 손잡이, 보행 동작과 조용한 합성 엔진음. 동작 줄이기·일시정지·음소거를 따른다. 모델은 재구성이며 실제 차량/승객/운행 시각을 주장하지 않는다.
- 지도 외부의 기존 건물·지형 양식은 유지된다. 이번 개선은 승객 시점과 차량·가까운 릴레이 거리 풍경에 집중했다.
