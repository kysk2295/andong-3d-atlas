- Codex 브라우저 1280×720, 모바일 viewport 390×844. 실제 휴대전화 성능 측정은 아님.

## 확인한 방문 흐름

1. 시장에서 식당까지 안내 보행, 찜닭 주문 18,000원 예시, 새 상차림. `jjimdak-table.png`.
2. 한 입 버튼 3회로 식사 완료. 같은 실내에서 계산대까지 걸어가기. 시점 보존, 카드 결제 시연. QR는 이번 회차에 정렬 도움 버튼을 사용하고 발급을 확인. 직접 QR 조작의 이전 회차 증거는 v3에 보존.
3. 식당 출구 → 연결 골목. 안내 도중 취소해 현재 위치와 첫 지점 대기 상태 유지. 이전 장면으로 복귀·새로고침 후 쿠폰 1장 유지. 다시 골목 이정표 → 공방 문까지 진행. `walk-to-workshop.png`.
4. 공방 마당에서 접수대까지 보행. 하회탈 12,000→10,800원, 1,200원 할인 확인. 탈 3단계는 이번 회차에 색칠 도움 버튼으로 완료해 연결 조건 검증. 수동 붓질/취소는 기존 v3 증거.
5. 공방 출구 → 승차 안내판 → 차량 문 → 실내 이동. `pickup-stop.png`. 기본 연결차량으로 실행. 택시·도보의 충돌 배치는 순수 경로 테스트로 검사했으며 이번 회차에 두 선택의 전체 수동 완주를 반복하지 않음.
6. 이동 연출 완료 → 차량 출입문 → 하차 구간 → 강변 보행로 → 월영교. 모바일 390×844로 이어서 실행. `mobile-disembark.png`.
7. 새 난간을 따라 월영정 내부까지 안내 보행. `mobile-pavilion.png`. 시작점으로 되돌아와 강변 연결 이정표 → 팝업 입구를 순서대로 통과. `mobile-riverside.png`.
8. 월영차회 부스로 걸어가 화면의 E 상호작용으로 국화차 4,000원 카드 결제 시연. 완주 화면에 식사/영수증/전통체험/이동/야간 5개 체크, 탈 체험1개·할인1,200원·팝업구매1개 표시. `mobile-completed.png`.
9. 완주 후 새로고침해 완료 상태와 구매 기록 유지 확인.

## 수정 중 발견한 문제

- 시장 원형 간판 뒷면 노출 → 회전 수정.
- 지붕 가장자리 Float32 반올림 때문에 음수 분수 거듭제곱/NaN 발생 → 바닥값 clamp. 곡면 지붕/정자 좌표와 법선 회귀 검사 추가.
- 연결 구간 복귀 버튼의 옅은 글자 → 공통 텍스트 버튼 스타일과 분리.
- 기존 물결 줄무늬/타원 수목 반복 → 수면 셰이더와 수목 군집 재작성.
- 마지막 시장 재진입 검증에서 새 출입문의 참조 누락을 발견해 수정. 시장 전체 생성과 출입문 존재 회귀 검사 추가. 수정 전 오류 로그는 브라우저에 남으므로 최종 로딩 이후 시각을 기준으로 확인.

## 범위

공간 내부와 짧은 연결 구간을 이동하는 3D 체험이다. 현장 지형을 끊김 없이 이어 붙인 오픈월드, 실측 복원, 실사 인물, 실제 QR·예약·결제 시스템은 아니다. 실제 거리·시간은 축약하고 공방·팝업의 기획 상태는 화면에 표시한다. 기존 지도 진입점 보존. 공개 배포 없음.

- 모바일 viewport 임시 설정 해제. 공개 배포·커밋·푸시 없음.
