# v1.18 지도 레이어 검증

## 구현
- 기존 3D Atlas 탐색 패널과 1인칭 체험의 지도 메뉴에 독립적인 관광주민증 혜택업체/릴레이 1·2·3단계 연결선 스위치.
- 업체 또는 단계 표식과 목록을 눌러 위치로 이동하고 혜택/단계 설명 확인. 선택된 레이어의 해제는 상세 정보도 닫음.
- 수집된 혜택 27곳 중 좌표가 연결된 6곳만 표식으로 표시; 좌표 미확인 21곳은 혜택 목록으로 제공.
- 1단계 원도심 식음·체험, 2단계 저녁 이동 구간, 3단계 월영교 야간 체류. 2번은 도로 경로의 거리 중간 지점이며 실제 정류장으로 주장하지 않음.
- 기존 79점/3,395m 공개 도로망 설명 경로를 사용. 실제 버스 노선/확정 운영 경로와 구분.
- 3D 연결선은 지형을 따라 15m 간격 이하로 보간; 화면상 선폭 유지. 1인칭 지도는 별도 WebGL 렌더러 없이 기존 수계·도로 좌표로 표시.
- 레이어 선택은 게임 진행과 별도 키로 보관. 지도 닫기/재열기 및 Escape 시 게임 일시정지 해제.

## 실제 브라우저 검수 (CUA)
- 데스크톱 지도 열기 → 릴레이 1/2/3 표식과 연결선 확인.
- 혜택업체 전체 → 겹친 5곳 확대 → 카페구름마루 지도 표식 선택 → 상호, 음료 5,000원 이상 10% 할인, 주소 및 수집일 표시.
- 표식 겹침 시 뒤의 다른 단계가 선택되던 문제를 발견해 묶음 표식/확대/개별 목록으로 해결하고 다시 확인.
- 두 레이어 모두 끔: DOM 표식 0, 연결 경로 0, 선택 정보 숨김 확인.
- 서린당(좌표 확인 전) 선택 → 수집 혜택만 표시, 가공 위치 없음.
- 지도 닫기 → 원래 식당 행동과 포커스 복구. 지도 다시 열기 시 레이어 상태 유지.
- 3D Atlas 단계 연결선과 3개 번호 확인. 혜택업체 목록에서 카페구름마루 선택 → 지도 이동과 혜택 표시.
- 3D Atlas 두 레이어 끔 → 데이터 상태 false/false, 표식 레이어 및 정보 숨김 확인.
- 390×844: 체험 지도 연결선, 3단계 선택, 닫기/재열기 정상. 가로 넘침 없음.
- 390×844: 기존 Atlas 탐색 패널에서 스위치 접근·변경 가능, 가로 넘침 없음.
- 데스크톱 및 모바일 브라우저 오류 기록 없음. 임시 화면 크기를 원복하고 검수 탭 정리.
- 사용자의 localhost 진행 기록은 변경하지 않음. 검수는 127.0.0.1 origin 사용.

## 자동 검증 및 제한
- 기존 검사와 새 지도 모델 검사 포함 168개 통과. 빌드 성공.
- 새 검사: 좌표 검증/미확인 업체 배제, 거리 기준 중간 지점, 두 레이어 독립성, 모바일/데스크톱 지도 비율, 출처 데이터 일치, 겹친 표식의 누락 없는 묶음.
- 수집 당시(2026-09-21) 혜택을 사용. 현재 운영·할인 조건을 새로 조사하거나 미확인 21곳을 지오코딩한 작업은 아님.
- 모바일은 브라우저 화면 크기 검수이며 실제 휴대폰 하드웨어 검수는 아님.
- graphify update 시도: 설치된 명령의 Python 인터프리터 누락으로 실패. graphify.log 참조.
