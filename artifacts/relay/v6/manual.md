# v1.14.0 · 식사에서 영수증 혜택까지

2026-09-29 · Codex IAB · 실제 UI 조작. 앱 상태를 주입하지 않았다.

## 구현

- 손가락 관절과 엄지 관절을 가진 손. 음식·젓가락과 카드·영수증을 잡는 자세를 구분한다.
- 음식 조각이 손과 함께 부드럽게 이동한다. 입 안내에 놓으면 0.62초 동작을 거쳐 한 입이 기록된다. 잘못 놓으면 원래 접시 위치로 돌아간다. 동작 중 중복 입력과 취소는 한 입을 추가하지 않는다.
- 주문한 음식이 식탁에 놓이는 짧은 상차림 연출.
- 결제 확인창에서는 시연 방법만 고른다. 이후 3D 계산대에서 카드 또는 시연 현금을 단말기의 금색 원에 직접 가져다 댄다.
- 확인 → 영수증 출력 → 출력물을 눌러 손으로 받기 → 챙기기 순서. 마지막 챙기기 전에는 PAY 상태를 저장하지 않는다. 실제 금융 결제는 없다.
- 결제 단말기와 영수증에 선택한 메뉴·금액·결제 방법 표시. 영수증 출력, 손에 든 영수증, QR 촬영 화면은 같은 그리기 함수를 사용한다.
- 모바일 390×844에서는 작업 물건을 축소하여 현금이 잘리지 않게 한다. 카메라는 식당 벽 안쪽을 유지한다.
- 단계별 키보드 대체 버튼과 취소를 제공한다. 키보드 동작도 출력·수령 단계를 거친다.

## 실제 실행 검증

1. 기존 식당 진입 상태에서 최신 빌드를 다시 열어 안동찜닭 18,000원 주문.
2. 음식 조각을 입 밖에 놓아 복귀 확인. 복귀 동작 중 추가 입력이 무시되는 것도 확인.
3. 세 조각을 각각 직접 드래그하여 1/3 → 2/3 → 3/3, 식사 완료.
4. 계산대로 걸어 이동. 카드 선택 후 잘못된 곳에 드롭: 결제 시작 안 됨.
5. 카드를 금색 원에 드롭: 확인과 출력 후, 출력된 종이를 클릭하여 손으로 수령. `receipt-in-hand.png`.
6. 수령 후 마지막 확인 전에 취소: PAY 미완료, '계산하고 영수증 받기'로 복귀.
7. 모바일 390×844: 현금 직접 드래그 → 출력 → 종이 클릭 → 수령 확인. `mobile-receipt-printed.png`, `mobile-receipt-in-hand.png`.
8. 새로고침 후 18,000원 현금 시연 영수증 복원.
9. 모바일에서 종이를 직접 드래그하여 QR 정렬, 인증 완료. 정렬 도움 버튼은 사용하지 않음. 동일한 메뉴/금액/현금 표시를 전화 화면에서 확인. `mobile-same-receipt-qr.png`.
10. 체험 10% 할인권 발급 → 골목의 두 구간 이동 → 공방 접수.
11. 하회탈 꾸미기 12,000원 → 1,200원 할인 → 10,800원. 시연 접수 후 여행 기록에서 안동찜닭·현금·인증 완료·할인 사용 완료 확인. `meal-to-workshop-discount.png`.
12. 뷰포트 복원. 현재 탭은 공방 접수 완료, 바탕색 칠하기부터 이어갈 수 있다.
