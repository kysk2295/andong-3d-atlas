# v1.10 수동 검증 · 2026-09-29

기존 지도 첫 화면 유지. 이번 범위는 릴레이 체험의 행동과 연결 구체화이며 공개 배포하지 않았다.

- 데스크톱: 간고등어 메뉴 선택·주문 → 3D 식사/초기 식사 UI → 현금 결제 시연 12,000원 → QR 가운데 정렬·인증 → 국화차 10,000원에서 9,000원 예시 할인 접수.
- 3D 국화꽃 세 송이를 화면의 다관으로 실제 드래그해 3/3 확인. 물 10% 부족, 90% 초과, 비우기 후 60% 성공 확인. 같은 규칙으로 찻잔 따르기 완료. 물 양은 접근성 버튼 경로로 검증했고, 실제 길게 누르는 입력을 유지하는 수동 시간 측정은 수행하지 않았다.
- 전통주: 누룩을 먼저 눌렀을 때 거절, 3D 쌀 오브젝트 클릭 후 순서대로 재료 완료. 발효 항아리→소주고리→받는 그릇, 완성 술병→표찰→포장 완료.
- 연결차량 탑승 중 3D 경로 전환, 위치 표식과 진행률 확인. 월영정 산책 후 팝업 진입.

- 새로고침 후 영수증·쿠폰 사용 프로그램·팝업 결제 방식·탈춤 점수 복원. 완주 기록도 유지.
