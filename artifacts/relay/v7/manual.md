## 조작 검증

사용자 진행 기록을 건드리지 않도록 동일 서버의 별도 127.0.0.1 origin에서 검증했다. 사용자 원래 localhost 화면은 식사·인증·탈 공예·저녁 이동을 마친 연결 동선에 있었으며 초기화하지 않았다.

1. 시작 후 3D 캔버스에 포커스를 따로 주지 않고 위 방향키 8회·오른쪽 3회: 전진·회전 확인.
2. 사진 창 닫은 뒤 ‘사진·현장 정보’ 버튼에 포커스가 있는 상태에서 ArrowDown: 계산대 고정 상태 해제와 이동 확인.
3. QR 체험 중 캔버스 방향키는 걷기가 아닌 영수증 정렬로 동작. 왼쪽·아래로 정렬 후 인식 및 할인권 발급 확인.
4. 결제 체험 중 캔버스 Enter: 카드 시연 진행. 출력된 영수증을 화면에서 직접 눌러 수령 후 다음 단계 활성화.
5. 390×844에서 뒤로 이동 버튼 짧은 탭과 왼쪽 회전 확인. `mobile-before-move.png`, `mobile-after-move.png`. 임시 화면 크기는 검증 뒤 복원.
6. 모달·입력칸·수정키 제외, 한글 자판의 물리 W 키, 대각선 이동 속도, 탭·취소·포커스 상실 정지는 자동 테스트로 검증.

- 새 찜닭 조각을 마우스로 잡아 입 안내까지 끌어 놓음: 1/3 증가. 나머지 두 입은 키보드 보조 조작으로 완료. `meal-direct-drag.png`.
- 식사 취소 후 새로고침: 주문은 유지되고 식사 완료로 잘못 기록되지 않음.
- 꽃 담기에서 다관 몸체에 떨어뜨려도 실패하던 좌표를 재현. 높이·수신 물체 판정을 수정한 뒤 동일 좌표 드래그가 성공. 세 꽃 모두 직접 드래그로 3/3 완료. `tea-direct-drag.png`.
- 물 붓기와 차 따르기는 10% 보조 조작 7회 후 양 확인, 완료 확인. 모델 주둥이와 물줄기의 연결은 자동 테스트로 별도 검증.
- 10% 체험 혜택 1회 적용: 국화차 시연 가격 10,000원 → 9,000원. 식사→혜택→체험 완료가 릴레이 UI에 반영됨.

## 남아 있는 한계

전체 공간·인물·음식을 사진측량한 실사 모델은 아니다. 실사진 참고 재구성과 재질 개선이다. 일부 인물·음식·도구·수목은 절차적 모델이므로 여전히 단순화된 모습이 남는다. 포인터 고정은 이전부터 인앱 브라우저에서 제한되어 드래그 시선 조작을 유지하며 이번 변경으로 해제하지 않았다.

AGENTS.md가 요구하는 `graphify update .`도 시도했으나 기존 graphify 실행 파일이 존재하지 않는 Python 3.12 경로를 가리켜 실행되지 않았다. 앱 빌드·테스트에는 영향 없으며 관련 없는 Python 환경은 수정하지 않았다.
