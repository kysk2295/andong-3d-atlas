# 밤마당 공간 디자인 참고
확인: 2026-09-30. 아래 이미지들은 로컬 디자인 검토 자료이며, 작품 이미지 자체를 배포용 장면이나 텍스처로 복제하지 않았다.

- 글래드스튜디오, 부산항 1부두 행사 조감도 (2025): https://kmong.com/portfolio/view/180635
  - 적용: 긴 공용 식탁, 촘촘한 전구선, 목재 바닥의 식음 구역, 부스 위 천 장식.
- Coro Urdaneta, Concept design — Night Market in Beijing (2020): https://www.behance.net/gallery/109171323/Concept-design-Night-Market-in-Beijing
  - 적용: 컨테이너형 키친과 열린 매대의 혼합, 상품·조리 도구 진열, 공연 관람 공간을 판매 공간과 분리.
- MIXC YARD2.0 Garden Season, MUSE Design Awards: https://design.museaward.com/winners-info.php?id=33138
  - 이미지 확인. 상세 페이지는 도구에서 열리지 않음. 적용: 목조 박공지붕 파빌리온, 연결 골목, 식재와 테라스.
- 사용자 제공 Google Doc / 4단계 (현표): (팀 내부 Google 문서, 링크 비공개)
  - 적용: F&B / 공연·전시 / 이벤트 / 수변 야경의 공간 분리, 직접 둘러보고 결제하는 1인칭 흐름. 부스 수·크기·상호·가격은 이 프로토타입의 제안값.
