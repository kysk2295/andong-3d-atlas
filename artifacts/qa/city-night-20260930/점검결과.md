# 전체 도시 야간 조명

- 전체 지도와 상세 지도 모두 일반 건물의 창문 조명을 강화했습니다.
- 건물별로 안정적인 조명 분포를 지정하여 켜진 창문의 비율, 밝기, 따뜻한 빛과 흰빛이 서로 다릅니다.
- 먼 거리에서는 창문 조명의 평균 밝기를 유지하여 축소 시 조명이 사라지는 현상을 줄였습니다. 지붕은 창문처럼 발광하지 않습니다.
- 상세 지도의 기존 가로등을 더 밝게 하고, 해당 위치의 지면과 교량 높이에 맞춰 은은한 바닥 조명을 추가했습니다.
- 낮과 다른 날씨에서는 창문 발광과 가로등 바닥 조명을 끕니다. 기존 야간 팝업 조명은 유지합니다.

## 검증

- 관련 검사 46개 통과: 건물별 조명 식별값이 전체·상세 건물에 전달되는지, 가로등의 지면·교량 높이, 가로등 없는 지역, 기존 지도 데이터 및 팝업 조명 포함.
- 배포용 빌드 통과. 기존 대형 청크 경고 있음.
- 데스크톱 전체 야경과 좁은 화면의 상세 야경에서 실제 창문 불빛 확인. 낮 전환 및 야경 복귀 확인.
- 실제 브라우저의 경고·오류 없음.
- 실시간 점광원을 추가하지 않고 기존 건물 재질과 가로등 조명의 일괄 렌더링을 사용했습니다.
- 저장소 지침의 graphify 업데이트는 로컬 Python 3.12 실행 경로 부재로 실행 불가.
