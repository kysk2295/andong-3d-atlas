# 전체 여정 수동 점검

- 3D 지도: 하회마을 선택, 골목 확대, 릴레이 연결선 표시, 전체 릴레이 링크 정상. 좌표 숫자 없음.
- 식당: 입장, 자리 이동, 안동찜닭 주문 정상. 음식 드래그 1회 및 버튼 2회로 세 입 완료.
- 계산: 시연 카드 드래그, 출력 영수증 클릭과 수령 정상.
- QR: 영수증을 휴대폰 화면으로 드래그하여 인증 성공, 할인권 발급.
- 공방 연결: 식당 출구와 골목 이정표를 거쳐 공방 입장 진행.
- 공방: 10% 할인 적용 12,000→10,800원 확인. 하회탈 3단계 완성, 색칠 중 취소/재개 정상. 여행 기록에 식사·인증·할인 사용·탈 공예가 기록됨. 새로고침 후 완료 단계 유지.
- 저녁 이동: 연결차량 탑승, 이동 연출 자연 완료, 월영교 하차 및 보행로 연결 정상.
- 월영교: 월영정 산책 완료. 팝업 이동 중 멈추기를 누르면 완료로 오인하지 않고 다시 이동 가능.
