## 검증 범위와 남겨 둔 사항

- 실제 결제·예약은 없는 시연 기능으로 점검했다.
- 모든 음식·공방·교통수단의 조합을 전수 점검한 것은 아니다. 직접 완주한 경로는 안동찜닭 → 하회탈 → 연결차량 → 월영교 → 찜닭 키친이다.
- 투호, 탈춤, 엽서의 개별 미니게임과 국화차·전통주 체험은 이번 수동 완주 범위에 포함하지 않았다. 관련 자동 검사는 전체 검사에 포함된다.
- 이동 중 경로 보기 버튼은 누르기 전에 이동 연출이 끝나 이번 수동 점검에서는 확인하지 못했다. 일반 지도 복귀와 코스 화면은 확인했다.
- 모바일 확인은 브라우저 화면 크기 기준이며 실제 휴대폰 기기 점검은 아니다.
- 공개 배포 사이트는 이번 점검 대상이 아니다.
