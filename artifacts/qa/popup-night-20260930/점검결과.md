# 팝업 부스 야간 조명

지도 야경 모드에서는 9개 부스의 전구, 처마 아래 조명, 실내와 간판의 따뜻한 빛, 바닥의 은은한 조명이 유지됩니다. 기존 클릭 반짝임은 조명 위에 겹쳐지고 효과가 끝나면 야간 조명으로 돌아옵니다. 낮과 다른 날씨에서는 기존 주간 조명으로 복원됩니다.

- 실제 브라우저에서 야경의 지속 조명, 낮 전환과 복원, 야경 재전환, 개별 선택 확인.
- 관련 테스트 12개 통과. 지속 조명, 클릭 종료 후 조명 복귀, 표시 끄기와 켜기, 날씨 변경, 최초 야경 생성 포함.
- 배포용 빌드 통과. 기존 대형 청크 경고 있음.
- 추가 실시간 광원 대신 공유 조명 텍스처와 발광 재질을 사용하여 지도 전체의 조명 계산량 증가를 피함.
- graphify 업데이트는 설치된 도구의 Python 3.12 경로 부재로 실행 불가.
