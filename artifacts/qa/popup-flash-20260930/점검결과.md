# 야간 팝업 부스 반짝임 확인

- 지도에서 야간 팝업 부스를 켜거나 팝업 배치로 이동하면 부스 전체가 금빛으로 2.4초 반짝입니다.
- 개별 부스 선택 시 해당 3D 부스와 배치도 번호가 반짝입니다. 같은 부스를 다시 선택하면 효과가 다시 시작됩니다.
- 효과 종료 후 기본 조명으로 돌아오며 선택 테두리는 유지됩니다. 표시를 끄면 효과가 정리됩니다.
- 움직임 줄이기 설정에서는 반복 점멸 대신 일정한 강조 후 서서히 원상복귀합니다.

## 검증

- 실제 브라우저에서 찜닭 키친 선택, 재선택, 간고등어 그릴로 선택 변경, 부스 표시 끄기와 켜기 확인.
- 3D 선택 부스의 밝기 변화와 배치도 번호의 발광을 화면에서 확인.
- 관련 테스트 11개 통과: 개별 재질 격리, 효과 재시작, 종료 및 숨김 시 원래 조명 복원을 포함.
- 배포용 빌드 통과. 기존 청크 크기 경고 있음.
- 브라우저 경고 및 오류 없음.
- 저장소 지침의 graphify 업데이트는 로컬 도구의 Python 3.12 실행 경로 부재로 실행 불가.

화면 기록과 tests.log, build.log, console.json을 같은 폴더에 저장했습니다.
